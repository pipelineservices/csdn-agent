# Cloudhydra Connectivity Runbook (Sample)

1. Validate that the Cloudhydra control plane is healthy.
2. Run connectivity checks from Cloudhydra to the target VPC or cluster.
3. Confirm IAM roles and endpoint policies allow the requested action.
4. Check recent deploys of Cloudhydra agents or sidecars.
5. If checks fail, collect diagnostics and escalate to the CSDN Hydra team.
